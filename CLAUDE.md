## 0. Decision levels — read this first

Every setting in this spec has one of three levels:

- **LOCKED** — defines what the experiment *is* (what is compared, what a reported number means, fairness).
  Do not change. If impossible, stop the dependent stage, write the problem + proposed change in
  `DECISIONS.md`, and continue with independent stages.
- **RULE** — the *value* depends on facts not known yet (hardware speed, memory, convergence), so the
  *selection rule* is fixed and you apply it. Log the chosen value and the evidence in `DECISIONS.md`.
- **FREE** — implementation details that do not change the meaning of any result (code structure, data
  loading, batching mechanics, vectorization, file formats, test implementation). Choose what works best;
  no logging needed.

When something is not covered: if it could change a reported number's meaning or the fairness of a comparison,
treat it as RULE (choose conservatively, apply identically to all compared models, log it). Otherwise FREE.

**Escalation triggers — stop and write a short note at the top of `VERIFICATION.md` under `## NEEDS HUMAN`:**
a LOCKED item cannot be satisfied; estimated full-run time exceeds the budget after the fallback ladder
(Section 9); a correctness test keeps failing after genuine attempts; a result falls far outside the sanity
ranges (Section 11) and no bug is found.

## 1. Working rules

1. **Fail loudly.** No silent fallbacks (no random embeddings when GloVe fails to load, no different dataset,
   no smaller model). Raise a clear error or follow the documented rule.
2. **Never claim a run happened unless it did.** Every result JSON includes a run manifest: start/end
   timestamps, git commit, config hash, seed, hardware string, path to its log file.
3. **Never fabricate or hand-copy numbers.** Tables, figures and report drafts are generated by scripts from
   `results/**/*.json`.
4. **Config is the single source of truth.** All hyperparameters in `configs/*.yaml`; every run saves its
   resolved config next to its results.
5. **Tests are mandatory.** Implement every test in Section 10. Do not weaken, skip or delete a test to make
   it pass. A test must check behavior, not just shapes.
6. **Smoke mode.** Every entry point supports `--smoke` (~1% data, 1 epoch, seed 0) finishing on CPU in a few
   minutes. Smoke outputs go to `results_smoke/`, never mixed with real results.
7. **Checkpoint and resume.** Each (experiment, model, seed) run has its own directory with `config.yaml`,
   `log.txt`, `metrics.json` (updated every epoch), `last.pt`, `best.pt`, and a `DONE` marker written last.
   Re-running a command skips runs with `DONE` and resumes runs with `last.pt`.
8. **Keep it simple.** Plain PyTorch, sklearn, gensim. No Lightning, Hydra, wandb, `torch.compile`.
9. After each phase, append to `VERIFICATION.md`: what was built, commands run, test pass/fail counts, key
   sanity numbers, links to log files.

## 4. Data (LOCKED)

- Corpus: WikiText-2 tokenized version (`Salesforce/wikitext`, config `wikitext-2-v1`), official splits.
- Preprocessing: lowercase; whitespace split; drop empty lines; append `<eos>` to each non-empty line; the
  dataset's own `<unk>` maps to our single `<unk>` id.
- Vocabulary: all types in the **training split only** (no min_freq cutoff). Specials: `<pad>`=0, `<unk>`,
  `<eos>`. Saved once to `results/vocab.json` with a SHA-256 hash; every model and Part III load this file.
- Record `results/data_stats.json`: tokens per split, vocab size V, `<unk>` rate per split.

## 5. Common evaluation setup, Parts I/II (LOCKED)

- Each split = one token stream, cut into non-overlapping chunks of L = 128 (inputs `t[i:i+128]`, targets
  `t[i+1:i+129]`). Last partial chunk padded with `<pad>`; padded targets excluded (`ignore_index`).
- No hidden state carried between chunks.
- n-gram evaluated on exactly the same chunks, context reset at each chunk start, scoring exactly the same
  target tokens.
- Perplexity = `exp(sum NLL / count of non-pad targets)` over the whole split. Report CE (nats/token) and ppl.
- Model selection (LR choice, early stopping, n-gram λ) uses validation only. Test is evaluated once per final
  model.

## 6. Part I models

### 6.1 n-gram (LOCKED design, RULE for λ)
Interpolated trigram `P = λ3·P_ML(w|u,v) + λ2·P_ML(w|v) + λ1·P_ML(w) + λ0·(1/V)`, λ ≥ 0, Σλ = 1; when a
higher-order context is unseen, renormalize λ over the available orders. RULE: choose λ by grid search (step
0.05) or EM on validation. Implement with dicts/Counters (not nltk.lm). Must return a full normalized
distribution over V for generation.

### 6.2 Neural models — architecture (LOCKED)
| setting | value |
|---|---|
| input embedding dim | 100 (matches GloVe-100d) |
| hidden / d_model | 256 |
| layers | 2 |
| dropout | 0.3 (after embedding, between layers, before output layer) |
| output layer | Linear(256 → V), **no weight tying** |
| context length | 128 |
| embedding init (Part I) | random normal std 0.1, trainable, `<pad>` row zero |

- RNN: `nn.RNN(tanh)`. LSTM: `nn.LSTM`. Transformer: embedding(100) → Linear(100→256) → + learned positional
  embedding (128×256) → 2 pre-LN `nn.TransformerEncoderLayer(d_model=256, nhead=4, dim_feedforward=1024,
  dropout=0.3, batch_first=True, norm_first=True)` with a **causal mask** → final LayerNorm → output layer.
- Shared interface: `forward(tokens[B,T]) -> logits[B,T,V]`; `encode(tokens[B,T]) -> hidden[B,T,256]`.
- Report params split: input embedding / core / output layer / total; trainable vs frozen.

### 6.3 Neural models — training procedure
| setting | level | value / rule |
|---|---|---|
| effective batch size | LOCKED | 32 sequences |
| micro-batch | RULE | 32 if it fits in 4 GB, else 16×2 or 8×4 with gradient accumulation; same for all models if possible, always logged |
| optimizer | LOCKED | AdamW, weight_decay 0.01, grad-norm clip 1.0 |
| LR schedule | LOCKED | RNN/LSTM constant; Transformer 200-step linear warmup then constant |
| peak LR | RULE | per architecture, sweep {3e-4, 1e-3, 3e-3}, 2 epochs, seed 0, pick lowest val loss; if best is at an edge, also try the next value (1e-4 or 1e-2) once. Part II reuses the Part I LSTM LR (no separate sweep). |
| epochs | RULE | max 40, early stopping patience 3 on val loss, restore best checkpoint; per-run wall-clock cap 90 min (logged if hit) |
| precision | LOCKED | AMP for all neural models: fp16 autocast + GradScaler, loss computed in fp32 (`logits.float()`); evaluation also under autocast. If the overfit/initial-loss tests or training show NaN/inf caused by AMP, escalate rather than mixing precisions across models. |
| seeds | LOCKED | [0, 1, 2] for every neural model in Parts I and II |

Per-epoch log: train loss (token-weighted), val loss, val ppl, epoch time, cumulative time, LR, peak GPU memory.

### 6.4 Cost measurement (LOCKED protocol)
- Training: wall time to best checkpoint and to stop, time/epoch, steps, tokens seen, hardware string.
- All benchmarks run in one dedicated script (`scripts/benchmark.py`) after training, in one session:
  - throughput: forward pass over the full test split, batch 32, 5 warmup batches excluded, median of 3 runs,
    tokens/sec — neural models on GPU, and all four models (incl. n-gram) on CPU as the common workload;
  - generation latency: 50 tokens, 1 prompt, batch 1, median of 5 runs.
- README notes: laptop on AC power, no other heavy apps, thermal throttling is a limitation.

### 6.5 Generation (LOCKED)
5 fixed lowercase in-vocab prompts in `configs/base.yaml` (5–10 tokens, Wikipedia style). Two settings applied
identically to all four models: greedy; temperature 0.8 + top-k 40 with fixed seed. 50 new tokens. Never
sample `<pad>`. Save `results/part1/generations.json` and per-model distinct-1, distinct-2, repeated-trigram
rate, `<unk>` rate.

## 10. Required tests (`pytest -q`)

1. vocab_train_only: vocab from train only; val/test-only words map to `<unk>`; all consumers share the hash.
2. ngram_normalized: probabilities over V sum to 1 (±1e-6) for 20 contexts incl. unseen; no zero prob on test.
3. causality: for each neural model in eval mode, changing tokens at positions > t leaves logits ≤ t unchanged
   (atol 1e-5), several t.
4. padding_excluded: loss with padding equals loss on the same data with pad positions removed; counted tokens
   equal non-pad targets.
5. ppl_definition: evaluator ppl equals a naive reference loop; n-gram and neural evaluators score the same
   target count.
6. initial_loss: untrained model loss ≈ ln(V) (±1.0).
7. overfit_one_batch: each neural model drives loss on one small fixed batch below 0.5 within 300 steps.
8. frozen_embeddings: frozen settings have `requires_grad=False`, no embedding params in optimizer,
   bit-identical weights before/after a short run; 5 sample GloVe rows equal the loaded vectors.
9. no_weight_tying: input embedding and output layer are different tensors.
10. part2_configs_match: resolved Part II configs differ only in embedding keys; Part II models' non-embedding
    params at init equal a fresh model with the same seed and differ from the Part I checkpoint.
11. pooling_excludes_pad: mean pooling of a padded sequence equals that of the unpadded sequence.
12. part3_no_leak: C selection never touches test; LM params unchanged after feature extraction.
13. determinism: two CPU smoke runs with the same seed give identical first 20 losses.
14. checkpoint_roundtrip: save → load → identical logits; resume continues from the right epoch/step.
15. generation_consistency: greedy generation equals argmax of a full forward pass on each growing prefix
    (proves generation is autoregressive and uses only past tokens).

## 11. Sanity ranges (flag, never "fix" by tuning on test)

- Initial loss ≈ ln(V) for the actual V.
- Rough test ppl at this scale: trigram ~200–400; RNN ~150–300; LSTM ~100–180; Transformer ~120–250. A small
  Transformer losing to the LSTM here is a legitimate result.
- LSTM test ppl < 60 → suspect leakage, causality or padding bug.
- AG News frozen mean-pooled accuracy ~0.75–0.90.
